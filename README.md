## My process

### Built with

- Semantic HTML5 markup
- CSS
- CSS Grid for page alignment
- Flexbox for the card layout
- Responsive sizing with `width` and `max-width`
- Google Fonts with the Outfit typeface

### What I learned

This project helped me practise building a small component from a visual reference. I worked with:

- Semantic elements such as headings, paragraphs, and a footer
- Flexbox for arranging the image and text vertically
- CSS Grid for centering content on the page
- CSS color values from a design specification
- Responsive card sizing for smaller screens
- The CSS box model, including padding and border radius

### Continued development

I want to continue improving my understanding of:

- The difference between `content-box` and `border-box`
- Default browser margins and how to control spacing precisely
- Responsive viewport units such as `vh` and `dvh`
- CSS Grid rows when a page contains both main content and a footer
- Accessible and descriptive image alternative text
- Comparing a finished page against reference screenshots at different viewport sizes
